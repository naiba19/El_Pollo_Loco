# 🌵 El Pollo Loco

**A fun 2D platform game built with JavaScript.**

Help Pepe explore the desert, collect coins and salsa bottles, defeat enemies and take down the Endboss!

### 🎮 Features
- Character movement, jumping and bottle throwing
- Collectible coins and salsa bottles
- Multiple enemies and an Endboss
- Health and collectible status bars
- Sound effects and background music
- Animated clouds and desert scenery
- Desktop and mobile touch controls

### 🕹️ Controls
- **← / →** Move
- **Space** Jump
- **D** Throw bottles

### 🛠️ Technologies
HTML5 · CSS3 · JavaScript

### ▶️ Run the Game
Open `index.html` using VS Code Live Server.
